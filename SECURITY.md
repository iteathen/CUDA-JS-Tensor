# Security Policy

CUDA-JS-Tensor is pre-release and has no supported production version. Please report suspected vulnerabilities through GitHub private vulnerability reporting when available. If that route is unavailable, open a minimal issue that requests a private maintainer contact without publishing exploit details, credentials, machine identifiers, or sensitive artifacts.

Public tensors and errors must not expose native pointers, handles, ordinals, provider paths, generated CUDA source, environment secrets, or unbounded backend logs.
