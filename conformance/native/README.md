# Native resolved-dense conformance

Run `npm run smoke:native:tensor-execution` with exact Node 26.7.0 on a CUDA-JS-qualified host. The runner packs and installs the current CUDA-JS-Tensor tarball into a temporary unrelated consumer, executes the public fixture, then removes the temporary installation.

The fixture covers view indexing plus materialization, fill, copy, cast including saturating special values, unary/binary half and bfloat behavior, broadcast, fixed-tree reduction, rank-2 SIMT matmul, a strict kernel-to-cuBLASLt-to-kernel f32 realization, exact fused-versus-unfused elementwise output, a fused f32-to-f64 dtype transition, fused NaN/signed-zero/infinity behavior, prepared replay and terminal CUDA-JS cleanup. It also compiles an item-parallel dense program as a public leaf library, imports it into an unrelated Device-JS kernel, executes four independent matmul/bias/reduction items, verifies four out-of-range no-write statuses and checks exact outputs. A pass qualifies correctness/lifecycle only on the recorded invocation profile. It does not establish performance, tensor-core use, Linux, another provider/GPU, multi-GPU behavior or production stability.
